## Checked and REJECTED

- **Internet Speed Test** — REJECTED on feasibility, honestly: a speed test is only as real as the endpoint it measures against. A static site has no owned bandwidth endpoint; timing downloads of third-party CDN files measures that CDN, not the user's connection, and the numbers would be theatre. Also the SERP is Ookla/Google-owned. Fails the no-server rule in spirit.
- **Generic Audio Converter / MP3-to-WAV as a head tool** — feasible (Web Audio API / ffmpeg.wasm) but no single pair outside mp4-to-mp3 (already on ToolPixi) shows a verified ≥100K figure in public sources this pass; demand fragments across dozens of pairs. Revisit as one "audio converter" page only if a verified head-term figure appears.
- **Online Voice Recorder** — feasible and tiny (MediaRecorder), but no published ≥100K/mo keyword figure could be verified in public sources this pass (category traffic exists via Vocaroo/123apps, keyword volume unverified). Below the evidence bar — watch list, not a build.
- **Image Upscaler (AI)** — real AI upscaling needs server GPUs; in-browser UpscalerJS/TensorFlow.js is 2x-only, slow, and visibly worse than the server tools ranking for the term. Would ship a fake-feeling tool. Rejected.
- **Webcam Recorder (standalone)** — no standalone ≥100K keyword; demand folds into screen recorder / voice recorder. Included as a mode inside #8 instead.
- **Barcode Scanner (standalone)** — a fraction of QR demand; included as a second mode inside #4 instead.
- **Online Notepad** — no verifiable ≥100K figure; commodity feature, not a search destination. Rejected.
- **Generic Video Converter page** — demand lives in specific pairs; the proven ones are covered (mp4-to-mp3 exists, video-to-gif is #9). A generic page would duplicate the video-compressor engine with an unproven head term. Rejected as a separate build.
- **Video-to-ASCII / novelty converters** — no volume evidence anywhere near the bar. Rejected.

## Build-order logic
Quick wins first (small builds, proven demand): Typing Speed Test, QR Code Scanner, Screen Recorder. Engine reuse next: GIF Maker (own engine), Video to GIF + Video Trimmer (existing ffmpeg.wasm). Canvas pair: Meme Generator, Photo Collage Maker. Documents pair (highest CPC): Invoice Generator, then Resume Builder (the one large build). OCR when ready for the heavier WASM payload.
