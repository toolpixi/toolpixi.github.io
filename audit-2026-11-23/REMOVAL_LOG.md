## How it was done
1. build.py: the 38 entries removed from `TOOLS` (drives homepage tiles, nav,
   llms.txt and the `__N__` tool count) and their 38 `PAGES.append(...)`
   blocks removed (drives page generation + sitemap). `RELATED_TOPUP` cleaned:
   entries for removed slugs dropped; removed slugs stripped from kept pages'
   top-up lists (otherwise layout() would KeyError on TOOL_BY_SLUG).
   Remaining references in kept pages (related_html lists + prose links) were
   cleaned/retargeted so no built page links to a removed slug.
2. Redirect stubs: GitHub Pages has no server 301s, so each removed path
   serves a lightweight stub `index.html` (meta-refresh 0s + canonical to the
   target + `noindex` + a short human note with a link). **Persistence:** the
   stubs are generated by build.py itself — see the `REDIRECT_STUBS` dict and
   the stub-writing block at the end of `main()` in build.py. Every future
   build rewrites them, and the stub folders live in the source tree, so the
   rsync deploy carries them. They are NOT in `pages`, so they never enter
   sitemap.xml. Do not delete the `REDIRECT_STUBS` block or the stub folders.
3. Expected after state: catalogue **122 tools**, sitemap **157 URLs**,
   ads.txt md5 unchanged.
