Random Name Generator

Paste your list of names and pick winners at random — raffles, teams, classroom cold-calls and secret gifts, with or without repeats.

Private by design: this tool runs entirely in your browser. Your files are never uploaded to a server, and nothing is stored.
—

How to use it

Paste your list. One name per line — entrants, students, team members. The sample list is only a starting point; replace it with your own.
Choose how many, and whether repeats are allowed. Tick “No repeats” for raffles and drafts, leave it off for quick classroom questions.
Pick. The names appear above, ready to copy. Pick again for a fresh draw — every draw is independent.

Raffles: one draw, no arguments

A raffle drawn by hand always leaves one person in the room convinced the draw was fixed — the hand hovered, the slip was folded differently, the organiser's friend won again. A random draw from a full list removes the hand entirely: every entrant has the same chance, the pick is made by the browser's random source, and the result is the result. Paste the complete entrant list — every name, no exceptions — tick "No repeats" so nobody wins twice, and draw one winner per prize.

For prizes of real value, make the draw auditable: screenshot each result as it lands, in order, and keep the list you drew from. If the draw happens in front of an audience, say the rule before the first pick — "one prize per draw, winners removed" — and then follow it exactly. A draw whose rules change after the result is a draw nobody trusts, however random it was. And if the audience should watch the decision happen rather than just hear the result, the Spin the Wheel tool does the same job with the ceremony attached.

Classrooms: a fair rota from the register

A class register is a list, and a list is all this tool needs. Paste the names, pick one, and the next reader, presenter or group leader is chosen with the same chance for every student — no pattern to spot, no suspicion about whose name keeps coming up. It works for the small jobs too: who reads the next paragraph, who goes first in the debate, which group presents first, who gets the window seat on the trip. The draw takes seconds, which is the point: the lesson carries on instead of stopping for a debate about fairness.

For a full round of turns, tick "No repeats" and work down the picks in order — that is the rota for the week, written by the draw rather than by the teacher's memory, and it guarantees every student is called exactly once before anyone is called twice. For a single quick question, leave repeats on: the same student may fairly be picked again, because each pick starts fresh. Whichever you choose, say it before the first draw — a rota the class agreed on is a fair rota, and one changed halfway through is not.

Teams, drafts and secret gifts

Splitting a group fairly is the same draw wearing a different coat. For two teams, draw with "No repeats" on and deal the picked names out in order: first name to Team A, second to Team B, third to Team A, and so on — the teams build themselves with no captain picking favourites and no last-picked sting, because nobody did the picking. For a draft order, draw the order itself: the first name drawn picks first, the second picks second, and the order is the draw.

Secret gifts run on the same rule with one extra step: draw the giver–receiver pairs with no repeats, then check that nobody drew themselves — if a name matches its own pair, draw that pair again. The list never leaves your browser, which matters when it is a class register or a customer list: there is no upload, no account and nothing to delete afterwards.

With repeats or without? The one choice that matters

Nearly every complaint about a name draw traces back to this single checkbox. Repeats allowed means each pick is independent — the right model for a quick question, a daily random student, or generating test data, where the same name coming up twice is harmless. Repeats off means drawing from a drum — the right model for raffles, drafts, presentation orders and secret gifts, where a duplicate winner is a scandal in miniature.

Repeats onQuick questions, daily picks, test data, "who answers next" — a name may fairly appear twice.
Repeats offRaffles, team drafts, presentation rotas, secret gifts — each name wins at most once.

Decide before the first draw, say it out loud, and stick to it. The tool enforces whichever you chose — it refuses to draw more unique names than the list holds rather than silently repeating one — but it cannot enforce the promise you made to the room. That part is yours.

Name picker vs wheel vs dice: which tool for which job

ToolPixi has three pickers, and they are not interchangeable. This name generator is the quiet workhorse: paste a list, draw names, copy the result — no ceremony, no animation, just the answer. The Spin the Wheel is the same draw with the ceremony attached, for the moments the audience should watch the decision happen. And the Random Number Generator is for numbers themselves — a range, a quantity, repeats or no repeats, sorted or not.

Choose by what the moment needs. If you need names on a list, quickly and privately, use this page. If the room must see the draw, spin the wheel. If it is a number — a winning ticket, a seat number — generate the number. The fairness is the same in all of them: the pick is made by your browser's random source, on your device, with nobody in the middle.

The draw nobody can argue with

Every group has a version of the same argument: who goes first, who presents next, who won the raffle, whose name comes out of the hat for the secret gift. A human drawing the name always looks suspicious to someone — the hand hovered, the slip was folded differently, the teacher obviously picked their favourite. A random draw from a list removes the human from the choosing entirely: the names go in, the tool picks, and the result is the result. That is the whole value of a name picker — not the randomness itself, which a hat also has, but the removal of doubt about who did the picking.

The "no repeats" option is the one with real work to do. With repeats allowed, each pick is independent — the right model for rolling a name to answer a question in class, where the same student can fairly be called on twice. With repeats off, the tool draws like names from a drum: each name can win only once, which is what a raffle, a team draft, a presentation order or a secret-gift draw needs. The distinction sounds pedantic until the moment a duplicated raffle winner has to be explained to a room; getting it right in advance is the entire point of using a tool instead of a hat.

Keep the list honest and the draw stays honest. Paste the full list — every entrant, every student, every team member — and let the tool pick from all of them; a draw from a partial list is a draw with the winner pre-decided. And because the names are picked on your device with the browser's own random source, the list itself never leaves your tab: no names uploaded, no entrants stored, nothing to delete afterwards.

Questions, answered

Is the pick truly random?

Yes. Names are chosen with your browser's crypto-grade random number generator — the same kind used for security keys. Every name on your list has an equal chance on every draw, and past picks never affect future ones unless you tick “No repeats”.

What does “No repeats” do?

Each name can be picked only once, like drawing names from a hat. Perfect for raffles, team drafts, presentation orders and secret-gift draws. If you ask for more unique names than your list holds, the tool tells you instead of guessing.

How many names can I pick at once?

Up to 10 at a time, from a list of up to 500 names. For a full ordering — a raffle order or a presentation rota — pick 10, note them down, and draw again with “No repeats” still on: the tool remembers nothing between draws, so keep the picked names out of the list yourself, or use the wheel's remove-winner mode instead.

Can I use it for a raffle with real prizes?

Yes. Paste the full entrant list, tick “No repeats”, and draw one winner per prize. Screenshot each result as your record. For a public draw where the audience should watch the decision happen, the Spin the Wheel tool does the same job with the ceremony attached.
