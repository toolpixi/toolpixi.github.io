## 1) MEDIUM — republication plan

### How it works in 2026 (researched 2026-11-13)
- Medium's **"Import a story"** tool (Stories page → *Import a story*, or medium.com/p/import) pulls a post
  in from its URL and **automatically sets the canonical link back to the original on toolpixi.com** —
  Google keeps crediting our page; the Medium copy cannot outrank or cannibalise it. It also backdates
  the story to the original publish date and appends an "Originally published at…" line.
- **Copy-pasting into a fresh draft does NOT set a canonical.** If import ever fails, the fallback is:
  editor → ⋯ menu → More settings → Advanced settings → tick *"This story was originally published
  elsewhere"* → paste the toolpixi.com URL → Save canonical link. Never publish a paste without this.
- Medium outbound links are nofollow — the value here is **brand exposure and name recognition**,
  not link equity. That is exactly the toolzin lesson (people searching the name).
- Timing rule: let the original get indexed first — **wait ~1–2 weeks after a guide goes live**
  before importing it.
- A Medium **Partner Program / paywall is NOT needed** and should stay off for these — free, public,
  maximum reach.
- Start with a **profile**, not a Publication. A publication can be created later (once 3+ stories
  are live) as "ToolPixi Guides" if the channel shows life.
