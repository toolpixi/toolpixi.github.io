The sizes people actually need

Upload systems are oddly specific: a marketplace wants 2000×2000 product shots, a signature must fit 400×200, a profile picture gets cropped to a square, and printing at 300 DPI turns a "big" photo small very quickly. Shrinking is the common case and stays crisp; remember that making an image larger cannot add detail, so a heavily enlarged photo will look soft no matter which tool does it. Pair this resizer with our Image Compressor to KB when a form limits both dimensions and file size. The full routine — exact pixels, exact kilobytes, and the mistakes that get uploads rejected — is in our guide to resizing an image for an online form.

Pixels, proportions and the stretch that gives itself away

Resizing sounds like one job and is actually three. There is resizing to exact pixels, when a platform demands 1200×630 for a link preview or 1080×1080 for a post. There is resizing by percentage, when a photo is simply too large and half the size will do. And there is the quiet third job underneath both: keeping the proportions true. Change the width without the height and faces stretch, logos warp and products look melted — the unmistakable signature of an image resized by someone fighting the tool instead of using it. This resizer locks the aspect ratio by default precisely so that mistake is hard to make.

The other misunderstanding is size in pixels versus size in kilobytes — they are cousins, not twins. Halving a photo's dimensions usually cuts its file size by far more than half, because the pixel count falls to a quarter. So when the real problem is an upload limit like "under 200KB", resizing the dimensions down is often the fastest route, with the Image Compressor finishing the job to an exact target. When the problem is a platform's required dimensions — a banner, a thumbnail, a profile slot — pixels are the language to speak, and this page speaks it directly.

One rule protects every resize: never enlarge a small image and expect sharpness. A 200-pixel logo stretched to 2000 pixels is the same information spread thinner, and it will look soft no matter what tool does it. Resize down freely; for going up, you need a bigger original.

Questions, answered

How do I resize an image to a specific size, like 1920×1080?

Choose your image, type 1920 as the width and 1080 as the height. With 'Keep aspect ratio' ticked, the picture fits inside that box without stretching; untick it to force the exact size.

What does the percentage box do?

It scales both dimensions together — 50% makes the image half as wide and half as tall (a quarter of the pixels). Typing a width or height clears it, and vice versa.

Will resizing make my photo blurry?

Shrinking stays sharp. Enlarging cannot invent detail that was never captured, so a much bigger version will look softer — we resize honestly rather than pretending otherwise.

Which format should I download?

'Keep format' preserves the original type. JPG is smallest for photos, PNG keeps transparency and sharp edges, WebP is a good middle ground for websites.
