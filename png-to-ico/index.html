A real icon file, not a renamed PNG

Renaming a .png to .ico fools nobody — Windows expects a specific binary format with one or more icon images inside. This tool builds that format properly: each size is rendered as a 32-bit image with a real transparency mask, packed into a standards-compliant .ico container, all in your browser. Need a favicon for a website instead? Our Favicon Generator builds the same kind of file named favicon.ico with one click.

Worked examples: what the tool actually builds

The default "All sizes" chip builds seven versions of your artwork into one file. The four small sizes are stored as 32-bit BMP entries, each with its exact byte size fixed by the format; the three large ones are stored as PNG-compressed entries, so their size depends on the artwork. These figures were produced by running the tool's own icon builder:

The four small entries together always weigh exactly 17,472 bytes, and the file's header plus its seven-entry directory adds 118 bytes — so the fixed part of a full "All sizes" icon is 17,590 bytes before the three PNG entries. A single-size file is smaller still: pick the 16 px chip and the whole .ico is exactly 1,150 bytes — a 6-byte header, a 16-byte directory entry and the 1,128-byte image. The 256 px entry is recorded as 0 in the file's directory, which is the ICO format's way of writing 256 — the number does not fit in a single byte.

Cropping is centre-first and predictable. A 1200 × 800 logo becomes an 800 × 800 square with 100 px trimmed from the left and 100 px from the right; a tall 800 × 1000 picture becomes 800 × 800 with 100 px trimmed from the top and bottom. Check the artwork survives that square before converting — a wide banner logo will lose its ends.

One file, three jobs. The download is named after your PNG with a .ico ending, and it holds the same seven sizes the Favicon Generator builds, so it works as a Windows app icon, a desktop shortcut icon, and — renamed to favicon.ico and placed in your site's root — a website favicon. Windows and browsers pick the size each place needs; nothing else has to be generated.

An ICO is not one icon — it is a drawer of them

A Windows .ico file looks like a single icon but is really a container: inside one file sit several versions of the same artwork at different sizes — 16×16 for taskbars and lists, 24 and 32 for desktops, 48 for tiles, and 256 for high-DPI displays and large-icon views. Windows picks the closest size to what it needs and scales that one, which is why a proper ICO looks crisp everywhere while a single-size file looks mushy somewhere. This tool builds that genuine multi-size container from your PNG, generating each size from the original artwork rather than stretching one.

Start with the right PNG: square, at least 256×256, with the artwork large in the frame and simple enough to survive being shrunk to sixteen pixels — fine lines and small text simply vanish at that size, which is why famous icons are bold shapes, not detailed illustrations. Transparency in the PNG is preserved in the ICO, so a logo-shaped icon stays logo-shaped against any desktop background. The result is the file Windows expects for application shortcuts, installer icons, folder customisation and legacy software — and with a rename to favicon.ico, it also serves as a website's browser icon.

The whole build happens in your browser on your device. Drop in the PNG, take back a real .ico — no uploads, no watermarks, and no pretending that a renamed PNG is the same thing, because Windows can tell the difference even when people cannot.

Questions, answered

What is an ICO file?

The icon format Windows uses for app and shortcut icons. A single .ico file holds several sizes, and Windows picks the right one for each place it appears.

Which sizes should I include?

The default 'All sizes' builds all seven — 16, 24, 32, 48, 64, 128 and 256 px — into one file, so Windows always has the size it needs. Pick a single-size chip only when one place needs one size, for example a 16 px icon for a list view.

Is the icon cropped?

Yes: icons must be square, so the image is cropped to a square from the centre. Use a logo or picture that reads well when centred and square.

Where do I use the .ico file?

Windows app icons, desktop shortcuts, and classic desktop software. For website favicons in modern browsers a PNG often works too — but .ico is the safe universal choice.
