How to use it

Pick the two dates — a start and an end, in either order.
Choose inclusive counting if both the first and last day should count (leave, rentals, stays).
Read the span in days, weeks, months and hours.

Everyday questions this answers

How many days of leave have I taken? How long until the visa expires, the contract ends, the baby is due, the project ships? Counting calendar days by hand goes wrong around month-ends and leap years; this calculator uses the real calendar so the number you quote is the number that is true. The months and years figures are honest approximations (months are not all the same length), while the day count itself is exact.
